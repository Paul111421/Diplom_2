# Diplom_2

Автоматизация API-тестирования сайта Stellar Burgers
в рамках обучения по программе подготовки тестировщика-автоматизатора
Яндекс.Практикум


| Технология    | Версия   | Примечание                                                                            |
|---------------|----------|---------------------------------------------------------------------------------------|
| Java          | 11       | Язык программирования, использованный в проекте.                                      |
| Selenium      | 3.141.59 | Фреймворк для автоматизации браузеров в рамках автотестирования.                      |
| JUnit         | 4.12     | Фреймворк автоматизированного тестирования, команды которого использовались в проекте |
| RestAssured   | 4.5.0    | Java-библиотека для автоматизации запросов к API веб-приложения                       |
| GSON          | 2.8.9    | Java-библиотека для конвертации объектов Java в JSON                                  |
| Jackson       | 2.13.0   | Java-библиотека для обработки JSON                                                    |
| Allure        | 2.10.0   | Фреймворк для вёрстки готовых отчётов автотестирования                                |
| AspectJWeaver | 1.9.7    | Расширение для внедрения дополнительного описания автотестов                          |
| Javafaker     | 0.15     | Java-библиотека для создания случайных данных для карточек пользователей              |
